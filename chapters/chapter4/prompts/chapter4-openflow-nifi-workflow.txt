## B) NiFi canvas (Snowsight — you cannot do this in SQL; give the reader exact steps)
The Alpha Vantage FX_DAILY API returns a nested JSON object with two top-level keys:
- "Meta Data" containing "2. From Symbol" and "3. To Symbol" (currency codes)
- "Time Series FX (Daily)" containing date-keyed objects with "1. open", "2. high", "3. low", "4. close"

Target table columns: trade_date, from_currency, to_currency, open_rate, high_rate, low_rate, close_rate.

Build a **4-processor flow** — order matters (Jolt BEFORE Split):

1. **InvokeHTTP** — "InvokeHTTP - FX Daily Rates"
   - HTTP Method: GET
   - Remote URL: https://www.alphavantage.co/query?function=FX_DAILY&from_symbol=USD&to_symbol=EUR&apikey=<YOUR_KEY>
   - Timer-driven, 300 sec (free tier: 25 req/day). Auto-terminate Original, Retry, No Retry.
   - Wire Response → JoltTransformJSON.

2. **JoltTransformJSON** — "JoltTransformJSON - Flatten FX Rates"
   - Jolt Transformation DSL: **jolt-transform-chain** (NOT the display name "Chain" — use the internal value).
   - Jolt Specification (3-operation chain):
     [
       {
         "operation": "shift",
         "spec": {
           "Time Series FX (Daily)": {
             "*": {
               "$": "rates[#2].trade_date",
               "1. open": "rates[#2].open_rate",
               "2. high": "rates[#2].high_rate",
               "3. low": "rates[#2].low_rate",
               "4. close": "rates[#2].close_rate"
             }
           },
           "Meta Data": {
             "2. From Symbol": "from_currency",
             "3. To Symbol": "to_currency"
           }
         }
       },
       {
         "operation": "modify-default",
         "spec": {
           "from_currency": "USD",
           "to_currency": "EUR",
           "rates": {
             "*": {
               "from_currency": "=(@(3,from_currency))",
               "to_currency": "=(@(3,to_currency))"
             }
           }
         }
       },
       {
         "operation": "remove",
         "spec": { "from_currency": "", "to_currency": "" }
       }
     ]
   - WHY 3 operations: shift restructures nested dates into flat array + extracts currency codes;
     modify-default fans currency codes into each rate element (critical — SplitJson loses parent fields);
     remove strips top-level currency fields that are now redundant.
   - Wire to SplitJson.

3. **SplitJson** — "SplitJson - Individual Rates"
   - JsonPath Expression: $.rates[*]
   - Each element becomes one FlowFile (~100 daily OHLC records per response).
   - NOTE: Jolt must run BEFORE Split because individual rate records need the currency codes
     from the sibling Meta Data object. Splitting first loses that context.
   - Wire split → PutSnowpipeStreaming.

4. **PutSnowpipeStreaming** — "PutSnowpipeStreaming - FX_DAILY_RATES"
   - Processor type: com.snowflake.openflow.runtime.processors.snowpipe.PutSnowpipeStreaming
     (from runtime-snowpipe-processors-nar; NOT "PutSnowpipeStreaming2")
   - Authentication Strategy: SNOWFLAKE_SESSION_TOKEN (automatic in SPCS/OpenFlow)
   - Database: RAW_DB, Schema: STREAMING, Table: FX_DAILY_RATES
   - Role: OPENFLOW_RUNTIME_ROLE
   - Record Reader: JsonTreeReader (add and enable this controller service)
   - Connection Strategy: STANDARD
   - Delivery Guarantee: At least once
   - Client Lag: 1 sec
   - Wire failure → Funnel or LogAttribute.

5. Start the flow and confirm rows:
   SELECT COUNT(*) AS rows_loaded, MIN(trade_date), MAX(trade_date)
   FROM RAW_DB.STREAMING.fx_daily_rates;

## Troubleshooting (common errors from field testing)
- "UnknownHostException: www.alphavantage.co" → EAI not attached to runtime. Run ALTER OPENFLOW RUNTIME OPENFLOW_DB.CONTROL.PARTNER_API_RUNTIME ADD EXTERNAL_ACCESS_INTEGRATIONS = (partner_api_access); (happens if the integration was re-created with CREATE OR REPLACE).
- "The role name provided in the request is invalid" → OPENFLOW_RUNTIME_ROLE not in runtime user's hierarchy. Fix: GRANT ROLE OPENFLOW_RUNTIME_ROLE TO ROLE OPENFLOW_ADMIN.
- "Snowpipe Streaming does not support columns of type AUTOINCREMENT..." → Table has a DEFAULT value. Recreate table without DEFAULT on any column. Re-grant INSERT/SELECT.
- JoltTransformJSON INVALID "validated against 'Chain' is invalid" → Use internal value jolt-transform-chain, not display name "Chain".
- Currency codes NULL after loading → Jolt spec must fan currencies into each rate element using modify-default with =(@(3,from_currency)) BEFORE SplitJson runs. Check processor order.
