## Facts (do not contradict)
- There is NO valid Snowflake SQL: CREATE PIPELINE, ALTER PIPELINE, EXECUTE PIPELINE, SHOW PIPELINES, or INFORMATION_SCHEMA.PIPELINE_HISTORY for OpenFlow. CREATE PIPE is Snowpipe (files only).
- OpenFlow is **gen 2** (gen 1 deployment creation retired 2026-09-09). Deployments and runtimes are SQL objects: CREATE OPENFLOW DEPLOYMENT techflow_ingest DEPLOYMENT_TYPE = SNOWFLAKE; CREATE OPENFLOW RUNTIME OPENFLOW_DB.CONTROL.partner_api_runtime IN DEPLOYMENT techflow_ingest ... EXECUTE_AS_ROLE = openflow_runtime_role EXTERNAL_ACCESS_INTEGRATIONS = (partner_api_access). Wait with SYSTEM$WAIT_FOR_STABLE_OPENFLOW_DEPLOYMENTS / _RUNTIMES.
- Custom flows still run on the NiFi canvas: Snowsight » Ingestion » Openflow » Launch Openflow » Runtimes tab » runtime canvas.
- SQL prepares: target table (NO DEFAULT values — Snowpipe Streaming requirement), database-scoped NETWORK RULE (EGRESS HOST_PORT), EXTERNAL ACCESS INTEGRATION, SECRET, role GRANTs including USAGE ON INTEGRATION, warehouse/table privileges.
- Monitoring: SHOW OPENFLOW DEPLOYMENTS; SHOW OPENFLOW RUNTIMES IN ACCOUNT. Credits for a Snowflake deployment: SNOWFLAKE.ACCOUNT_USAGE.METERING_HISTORY WHERE SERVICE_TYPE = 'OPENFLOW_COMPUTE_SNOWFLAKE'. OPENFLOW_USAGE_HISTORY covers BYOC only (empty for this lab).
- EAIs bind to a runtime with the EXTERNAL_ACCESS_INTEGRATIONS parameter (CREATE or ALTER OPENFLOW RUNTIME ... ADD EXTERNAL_ACCESS_INTEGRATIONS). Never CREATE OR REPLACE a network rule or EAI: it silently detaches it from the runtime.
- SHOW OPENFLOW DATA PLANE INTEGRATIONS / RUNTIME INTEGRATIONS are gen 1 objects. Do not use them for this lab.

## Troubleshooting reference
- "The role name provided in the request is invalid" → GRANT ROLE OPENFLOW_RUNTIME_ROLE TO ROLE OPENFLOW_ADMIN
- "Snowpipe Streaming does not support columns of type AUTOINCREMENT..." → Table has DEFAULT. Recreate without DEFAULT.
- JoltTransformJSON INVALID → Use internal value jolt-transform-chain, not "Chain".
- Currency codes NULL → Jolt modify-default with =(@(3,from_currency)) must run before SplitJson.
